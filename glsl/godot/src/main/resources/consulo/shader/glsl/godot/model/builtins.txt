# Format (parsed by GodotBuiltinsParser):
#   '#' starts a comment line; blank lines are ignored.
#   A section header is "[<kind> [<name>] @ <target> <target> ...]".
#   [functions ... @ <shader_type>:<context> ...]  one built-in function per line:
#       <return type> <name>(<[in|out|inout] type name[?]>, ...)   "?" marks an optional parameter
#   [variables ... @ <shader_type>:<context> ...]  one built-in variable per line:
#       <in|out|inout> <type> <NAME>    in = read-only, out = write-only, inout = read/write
#     <context> is "common" (anywhere in that shader type) or a processing function
#     (vertex, fragment, light, start, process, sky, fog).
#   [render_modes ... @ <shader_type> ...]     one render mode per line
#   [stencil_modes ... @ <shader_type> ...]    one stencil mode per line
#   [hints ... @ <uniform type> ...]           one uniform hint per line
#
# Corrections against gdshader-support: COLLISION_NORMAL is vec3 and COLLISION_DEPTH is float, USERDATAX is
